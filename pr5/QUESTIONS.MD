# Контрольные вопросы

1. Чем стрелочная функция `fn` отличается от классической анонимной функции `function`?
   `fn` записывается короче: тело состоит из одного выражения, которое возвращается автоматически (без `return`), а внешние переменные захватываются сами и по значению. В классической `function` может быть любое число инструкций, нужен `return`, а внешние переменные перечисляются через `use` (в том числе можно по ссылке `use (&$x)`).

2. Как `fn` захватывает переменные из внешней области видимости? Почему изменение переменной после создания функции не влияет на неё?
Автоматически и по значению, в момент создания функции. Внутри `fn` хранится копия значения, поэтому позднее изменение внешней переменной на неё не действует.

3. Можно ли записать в теле `fn` несколько инструкций? Как обойти это ограничение, если логика сложная?
   Нет, тело `fn` это одно выражение. Для сложной логики используют классическую анонимную функцию `function () use (...) { ... }` или обычную именованную функцию, а при необходимости `fn` вызывает её в своём выражении.

4. Что возвращают `array_map`, `array_filter` и `array_reduce`? Чем отличаются их callback-функции?
   `array_map` возвращает новый массив результатов применения функции к каждому элементу. `array_filter` возвращает массив элементов, для которых callback вернул `true`. `array_reduce` возвращает одно значение.

5. Как работает оператор `<=>` и почему он удобен в `usort()`?
   Оператор «космический корабль» сравнивает два значения и возвращает `-1`, если левое меньше, `0` при равенстве и `1`, если левое больше. Именно такое число ожидает `usort()` от функции сравнения, поэтому сортировка записывается одной короткой строкой: `fn($a, $b) => $a['age'] <=> $b['age']`.

6. Что выведет код `$f = fn($x) => fn($y) => $x * $y; echo $f(2)(5);`? Объясните.
   Выведет `10`. `$f(2)` возвращает вложенную стрелочную функцию, в которой `$x` захвачен и равен 2, а вызов этой функции с аргументом 5 даёт `2 * 5 = 10`.
